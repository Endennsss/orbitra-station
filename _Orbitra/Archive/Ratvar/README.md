# Архив культа Ратвара Orbitra

Статус: отключён по просьбе владельца проекта 28.09.2026, сохранён для дальнейшей доработки.

Здесь находятся текущие исходники, включая незакоммиченные изменения Crystal и Eminence,
прототипы, локализация, изображения, звуки, инструменты импорта, тесты и документация.
Пути внутри архива повторяют исходные пути относительно корня репозитория.
Все 399 перенесённых файлов проверены по SHA-256 до и после перемещения;
исходные хеши и размеры записаны в `manifest.json`.
Локальный `.gitattributes` запрещает нормализацию переводов строк в архиве,
поэтому контрольные суммы сохраняются после коммита и клонирования.

Архив находится вне `Content.*`, `Resources` и `Tools`, поэтому стандартные проекты
не компилируют его C#, загрузчик не читает прототипы, а упаковщик игры не включает
его ресурсы. Режим, роли, выдача через админку, писания, механизмы, команды тестирования
и обработчик культового канала больше не регистрируются. Старые записи changelog
оставлены как история. Ванильные материалы, язык, декоративные предметы и базовый
админский MobRatvar не относятся к этому архиву и сохранены.

Неопубликованные записи 83–87 сохранены в `pending_updates.yml` отдельно от активного
changelog: они описывают архивную разработку и не должны анонсироваться в Discord
как доступные игрокам функции. Активная запись 88 сообщает об отключении культа.

Это не ZIP и не удаление реализации. Лицензии, `meta.json`, `attributions.yml` и
реестры происхождения ресурсов сохранены без изменения. Не распространять
производные ресурсы Bee под другой лицензией.

Существующие ZIP-пакеты хостинга и уже запущенные процессы этим переносом не меняются.
Для отключения на хостинге нужен новый пакет; для локальной игры нужна свежая сборка
и перезапуск клиента/сервера. В карты с сохранёнными объектами OrbitraRatvar сначала
нужно внести изменения: архивирование не создаёт миграции таких пользовательских карт.

## Проверка сохранности

Из корня репозитория:

```powershell
pwsh ./_Orbitra/Archive/Ratvar/verify.ps1
```

Проверка подтверждает хеши, отсутствие файлов по активным путям и подключений культа.
Она не проверяет игровую работоспособность архивной реализации.

После переноса: проверка архива прошла три раза подряд; DebugOpt-сборка клиента,
сервера и зависимостей YAML-linter завершилась без ошибок. YAML-linter: ошибок нет,
118,4 с. Проверка DLL клиента, сервера, общей библиотеки и интеграционных тестов
не обнаружила идентификаторов OrbitraRatvar. `git diff --check` чистый.
Headless-клиент успешно проверил IL и загрузил главное меню без ошибок;
проверочный процесс остановлен. Визуальная проверка игрового раунда не проводилась.

## Возвращение к разработке

1. Сначала проверить актуальные правила `.agents` и аудит в архивном
   `Resources/ServerInfo/Guidebook/_Orbitra/RATVAR_PORT_AUDIT.md`.
2. Вернуть файлы из манифеста в соответствующие пути корня репозитория.
   Если путь уже существует, сравнить содержимое вручную, не перезаписывать его автоматически.
3. Восстановить четыре подключения ниже. Учитывать изменения API после архивации.
4. Собрать клиент и сервер, запустить профильные тесты, YAML-linter и игровую проверку.
   Не считать незавершённые сценарии аудита автоматически принятыми.

```csharp
if (TryHandleOrbitraRatvarChat(source, message, desiredType, shell, player)) return; // Orbitra-Edit - закрытый канал до обычной речи и мёртвого чата
```


В `Content.Server/StationEvents/Events/AnomalySpawnRule.cs` и `PowerGridCheckRule.cs`
заменить обычный выбор станции на прежний фильтр:

```csharp
if (!TryGetRandomStation(out var chosenStation, station => !TryComp<Content.Server._Orbitra.Ratvar.OrbitraRatvarEventTargetComponent>(uid, out var target) || station == target.Station)) // Orbitra-Edit - ограничиваем событие Eminence его станцией
```

Новые события Eminence из прерванного продолжения не реализованы; последняя сохранённая
версия поддерживает аномалию и проверку энергосети. Архивация не дополняет этот набор.
