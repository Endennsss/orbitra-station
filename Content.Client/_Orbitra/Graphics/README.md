# Bloom Orbitra

Система `OrbitraLightBloom` написана для Orbitra и распространяется по MIT-лицензии репозитория.
Она собирает `unshaded`-слои каждого спрайта в локальную маску с запасом по краям.
`TileEmission` обрабатывается отдельным общим проходом под спрайтами.
Маска источников собирается в полном разрешении и уменьшается усреднением блоков 4x4/2x2,
чтобы тонкие индикаторы не исчезали между выборками при движении камеры.
Маска размывается плотным нормализованным гауссовым ядром и накладывается в `WorldSpaceBelowFOV`.
Штатная карта освещения, конусы PointLight и UI не являются источниками Bloom.

Перекрытие повторяет порядок Clyde: `DrawDepth`, `RenderOrder`, экранный край спрайта и `EntityUid`.
Силуэты передних спрайтов закрывают источник до размытия и готовый ореол при композиции.
Маска учитывает прозрачность текстуры, слоя и спрайта в полном разрешении.
Сам источник и спрайты позади него не вырезают ореол: предмет на консоли закрывает её свечение,
а корпус консоли сохраняет собственный Bloom.

Источники упаковываются в ячейки общего атласа: маска, выборка и два прохода размытия
выполняются на группу, а не отдельно для каждой лампочки. Scissor ограничивает запись
ячейкой, ядро размытия не читает соседние ячейки. Атлас ограничен 1024 пикселями по стороне
в полном разрешении; источник крупнее этого размера получает отдельную ячейку.
Буферы переиспользуются между группами, невидимые за границами кадра ореолы пропускаются.

Композит использует точную обратную матрицу маски, включая масштаб, поворот и запас по краям.
Промежуточные проходы используют экранные прямоугольники, чтобы не переворачивать ось Y.
RGB содержит энергию с учётом прозрачности источника, alpha равна единице: это необходимо для
смешивания `SrcAlpha/DstAlpha` в Clyde. Сила применяется один раз после размытия.
Low и Medium используют четверть разрешения, High — половину. Мировой радиус одинаков
для всех уровней качества, с ограничением в 16 texel маски при сильном приближении камеры.

Публичный репозиторий Imperial Space использовался только как архитектурный ориентир для увеличенной
карты света и штатного blur-прохода. Код, шейдеры и ресурсы Imperial Space не переносились.
