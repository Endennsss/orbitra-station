# Bloom Lime Station

Система `LimeLightBloom` написана для Lime Station и распространяется по MIT-лицензии репозитория.
Она собирает `unshaded`-слои спрайтов и `TileEmission` в отдельную маску с запасом по краям.
Маска источников собирается в полном разрешении и уменьшается усреднением блоков 4x4/2x2,
чтобы тонкие индикаторы не исчезали между выборками при движении камеры.
Маска размывается плотным нормализованным гауссовым ядром и накладывается в `WorldSpaceBelowFOV`.
Штатная карта освещения, конусы PointLight и UI не являются источниками Bloom.

Композит использует точную обратную матрицу маски, включая масштаб, поворот и запас по краям.
Промежуточные проходы используют экранные прямоугольники, чтобы не переворачивать ось Y.
RGB содержит энергию с учётом прозрачности источника, alpha равна единице: это необходимо для
смешивания `SrcAlpha/DstAlpha` в Clyde. Сила применяется один раз после размытия.
Low и Medium используют четверть разрешения, High — половину; радиусы составляют 8/12/16 пикселей
исходного спрайта с ограничением в 16 texel маски при сильном приближении камеры.

Публичный репозиторий Imperial Space использовался только как архитектурный ориентир для увеличенной
карты света и штатного blur-прохода. Код, шейдеры и ресурсы Imperial Space не переносились.
