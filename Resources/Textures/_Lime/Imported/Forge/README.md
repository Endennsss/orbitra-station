# Текстуры Forge для Lime Station

Источник: [Forge-Station/Monolith](https://github.com/Forge-Station/Monolith),
коммит [0a07e9bfb0febd7a10965f28a41c55ac22279e8e](https://github.com/Forge-Station/Monolith/tree/0a07e9bfb0febd7a10965f28a41c55ac22279e8e/Resources/Textures).

Подключён 61 разрешённый RSI-набор в 42 файлах прототипов: 13 стен, 3 окон,
3 светильников, 4 дверей/шлюзов, 21 предметный набор, 12 других конструкций и 5 одежды.
Импортированы только реально используемые отличия; новая неподключённая библиотека
не создаётся. Совпадающие изображения не подменяются ради изменения пути.
Наборы сопоставлены по происхождению и совместимым состояниям/направлениям.
Игровые компоненты, механики и прототипы Forge не импортированы.

## Авторство и распространение

Оригинальные PNG, `meta.json` и имеющиеся `.license` сохраняются без изменения байтов.
В `copyright` и `source` сохранены авторы, происхождение и предыдущие изменения;
их нельзя подменять авторством Lime Station. Перенос не означает одобрения авторами.
60 наборов сохраняют CC-BY-SA-3.0, 1 — CC0-1.0. Полные тексты находятся в `LICENSES/`.
При распространении сохраняйте этот файл, тексты лицензий, реестр и метаданные.
При переработке CC-BY-SA-графики указывайте изменения и соблюдайте ShareAlike
для производной графики. Лицензия кода Lime Station не заменяет лицензии изображений.

Графика с NC, All rights reserved, неясным авторством или выявленными проблемами
исключена. Полный список отклонённых наборов — в `import_manifest.json`.
Индивидуальная разрешающая лицензия ресурса обязательна: общая лицензия Forge
не является разрешением на копирование его закрытой графики.
Опубликованные метаданные не гарантируют полной цепочки прав первоначального автора;
обоснованные замечания правообладателей требуют отдельной проверки.
Этот импорт не является аудитом всех ранее существовавших ресурсов билда.

`import_manifest.json` фиксирует источник и части реестра. Каждый набор содержит
авторство, индивидуальную лицензию/URL и SHA-256 всех исходных файлов.
Статистика совместимых путей включает потенциальные сопоставления;
фактически подключена только графика, указанная выше.

```powershell
node Tools/_Lime/import_goob_textures.mjs . --verify --forge
node Tools/_Lime/import_goob_textures.mjs . --verify-index --forge
```
