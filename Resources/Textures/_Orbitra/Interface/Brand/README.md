# Orbitra logo

`logo.png` is the unmodified `Orbitra logo(3).png` supplied by the user in the task on 2026-09-21, with an explicit request to integrate it into Orbitra.

No original artist or separate redistribution license was supplied. Do not attribute it to Space Wizards or assume the code's MIT license covers this image.

`starfield.png` uses the same emblem over the first frame of the Orbitra docking sky in `procedural_sky.swsl` (`docking_background = true`, `phase_time = 0`). Its edges fade to the engine's black startup background. The loading bar is drawn by the engine.
