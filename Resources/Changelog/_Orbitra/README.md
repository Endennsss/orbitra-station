# Обновления Lime Station

Заполняй `updates.yml`: этот журнал показывается отдельной первой вкладкой
в окне «Обновления» и доступен всем игрокам. Журналы апстрима остаются отдельно.

Каждый выпуск — новая запись в `Entries`. `id` должен быть уникальным и больше
предыдущего: по нему клиент определяет непрочитанные обновления. Не перенумеровывай
опубликованные записи. Укажи фактического автора и дату выпуска в ISO 8601.
Текст для игроков пиши по-русски; типы сохраняй как `Add`, `Remove`, `Fix`, `Tweak`.
Добавление записи требует пересборки/публикации ресурсов клиента.

Шаблон новой записи (замени значения и добавь в `Entries`, не отдельным документом):

```yaml
- id: 2
  author: Имя автора
  time: '2026-09-16T00:00:00+00:00'
  changes:
  - type: Add
    message: Что появилось для игроков.
  - type: Fix
    message: Какая проблема исправлена.
```

Не перечисляй ещё не включённые или не опубликованные функции как доступные.
Перед коммитом проверь уникальность id, четыре допустимых типа и запуск окна
«Обновления». JSON/YAML-формат данных журнала проверяется при загрузке клиентом;
обычный прототипный YAML-линтер не заменяет эту проверку.
