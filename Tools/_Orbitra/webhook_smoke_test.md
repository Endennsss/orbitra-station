# Проверка уведомлений Orbitra

Этот тестовый файл нужен для ручной проверки PR и Discord webhook.
Игровые механики не меняются.

1. Откройте PR из `features/webhook-smoke-test` в `master`.
2. Проверьте карточку нового PR в Discord: автор, название, ссылки и серый цвет.
3. Дождитесь проверок GitHub Actions.
4. После слияния проверьте тестовое обновление №92 в Discord.

Запись №92 помечена как тестовая. До слияния changelog в Discord не отправляется.
