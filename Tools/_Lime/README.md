# Импорт текстур Goob Station и Monolith

`import_goob_textures.mjs` работает с Node.js без дополнительных пакетов.
Он отбирает стены, двери, предметы и одежду с явной лицензией из белого списка,
сохраняет исходные файлы, проверяет RSI и сопоставляет совместимые состояния.
Запреты NC, неясное авторство, повреждённые файлы и явные отсылки к отдельным франшизам
исключаются. Проверка метаданных не заменяет установление цепочки прав при споре.

```powershell
node Tools/_Lime/import_goob_textures.mjs <checkout-Goob> --audit
node Tools/_Lime/import_goob_textures.mjs <checkout-Goob> --copy
node Tools/_Lime/import_goob_textures.mjs <checkout-Goob> --plan <папка-вне-репозитория>
node Tools/_Lime/import_goob_textures.mjs . --verify
node Tools/_Lime/import_goob_textures.mjs . --verify-index
```

`--copy` переносит только исходные графические ресурсы и отказывается перезаписывать
изменённые файлы. `--plan` создаёт во внешней временной папке патчи привязок и реестра
для просмотра и применения через редактор патчей; сам прототипы не меняет.
При повторном импорте сравните новые реестры с существующими перед применением.
После изменения прототипов обязательно запускайте YAML linter и проверку клиента.
Полные тексты индивидуальных лицензий должны присутствовать рядом с импортом.
Для Monolith добавьте `--monolith` ко всем командам выше и укажите его checkout.
Этот режим рассматривает все RSI с явной допустимой лицензией, включая окна,
светильники, энергетику, мебель, существ и эффекты. Совместимые варианты Frontier
имеют приоритет; новые механики не импортируются. У ЛКП заменяются корпус и рама,
а штатные индикаторы каналов питания сохраняются.

`connect_monolith_textures.mjs <checkout-Monolith> <папка-вне-репозитория>`
создаёт дополнительные патчи подключения уже импортированных ресурсов. Он учитывает
переименования из предыдущих реестров, варианты других форков в Monolith и одинаковые
ID/поля компонентов. Обычные шлюзы адаптируются отдельно: четырёхнаправленная основа
Monolith и штатные эффекты Lime Station. Патчи нужно просмотреть и применить;
после этого обязательны YAML linter и загрузка клиента. Без подходящего существующего
объекта ресурс остаётся в библиотеке — скрипт не придумывает новые игровые механики.
`--verify-index` дополнительно проверяет, что Git сохранил исходные байты всех
импортированных файлов в индексе перед коммитом.
