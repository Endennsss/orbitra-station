# Базовый интерфейс Orbitra

Обычные окна `FancyWindow` и `DefaultWindow` автоматически получают общую тему
при открытии. В новом окне не нужны `OrbitraEntryWindow.Attach(this)` или
`OrbitraEditorStyles.Apply(this)`: достаточно штатного `Open`/`OpenCentered`.
Оформление подключается до первого показа и распространяется на элементы,
добавленные позже. Покадрового обхода дерева нет.

## Модули

- `OrbitraWindowThemeController` наблюдает окна менеджера UI.
- `OrbitraWindowTheme` выбирает общую рамку для поддерживаемого типа окна.
- `OrbitraControlTheme` оформляет стандартные кнопки, поля, списки, вкладки и
  прокрутку. Явная геометрия и функциональные обработчики остаются у виджета.
- `OrbitraEntryWindow` отвечает за открытие, фокус, анимацию закрытия и очистку
  подписок при закрытии/удалении. Штатные `Close` и `Dispose` немедленные.
- `OrbitraDefaultWindowChrome` адаптирует рамку движка без изменения RobustToolbox.
- `OrbitraEngineMenus` содержит только специфичную раскладку спавнера и toggles.

Цвета берутся из `OrbitraPalettes`, правила — из общих sheetlet, размеры рамки —
из `OrbitraUiMetrics`. Исправление общей темы не требует правок каждого окна.

## Особые интерфейсы

Добавьте `OrbitraNativePresentation` в `StyleClasses` окна до первого открытия,
если ему нужна полностью собственная презентация. Тот же класс исключает
отдельное поддерево элементов, если задать его до подключения к оформленному
дереву. Уже применённые стили задним числом не отменяются.

Нестандартные окна на собственном `BaseWindow` продолжают использовать свои
адаптеры. Если появляется новый общий тип рамки, адаптер добавляется в модуль,
а не в каждый экран.

## Специализированные раскладки

Для редактора, которому нужна прежняя подгонка и перестройка содержимого,
укажите `StyleClasses="OrbitraEditorLayout"` в корне XAML. Профиль подключается
централизованно; вызовы в конструкторе не нужны. Обычная тема не изменяет позицию,
размеры и ограничения окна: их задаёт владелец через штатный API.

`OrbitraEditorStyles.Apply` сохранён для ранее настроенных редакторов. Он может
менять горизонтальную прокрутку, ширину кнопок и структуру отдельных контролов.
Не используйте его просто ради цвета или рамки нового окна. Общая тема и этот
модуль имеют отдельные маркеры, поэтому специализированную раскладку можно
применить после базового оформления без дубликатов подписок.

Тесты контракта: `OrbitraDefaultThemeTest`. Они проверяют обычные окна без ручных
вызовов, динамические элементы, исключения, геометрию, повторное открытие,
позиционирование и совместимость со специализированными раскладками.
