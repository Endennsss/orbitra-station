# Скины призраков Orbitra

В панели наблюдателя доступна кнопка «Скины». Меню показывает обычный облик
и три дополнительных скина: Mauler, голографический карп и космодракон.
Выбор применяется сервером и виден остальным наблюдателям.
Настройка `orbitra.ghost_skin` хранится в клиентском конфиге и повторно запрашивается
при появлении нового призрака. Неизвестный сохранённый ID заменяется обычным обликом.

## Добавление скина

Добавьте прототип `orbitraGhostSkin` в `Resources/Prototypes/_Orbitra/Ghost`:

```yaml
- type: orbitraGhostSkin
  id: OrbitraGhostSkinExample
  name: orbitra-ghost-skin-example
  description: orbitra-ghost-skin-example-description
  icon:
    sprite: Objects/Specific/Mech/mecha.rsi
    state: mauler
  sprite:
    sprite: Objects/Specific/Mech/mecha.rsi
    state: mauler
  opacity: 0.45
  order: 20
```

Добавьте `name` и `description` в обе локали. `opacity` должна быть конечным числом
больше нуля и не больше единицы. `order` задаёт порядок в меню.
Отсутствующий `sprite` означает восстановление штатного облика с причиной смерти.

## Устройство и проверки

Клиент отправляет только ID прототипа. Сервер выбирает цель из текущей сущности
отправителя и проверяет, что это призрак; изменить чужого персонажа таким запросом
нельзя. Состояние скина реплицируется через `OrbitraGhostSkinComponent`.

Дополнительные скины используют отдельный слой спрайта с непрозрачностью 45%. Исходный слой призрака
сохраняет состояние причины смерти и возвращается при выборе обычного облика.
Скин не меняет сущность, физику, маски видимости, разум, способности или экипировку.

облика, число слоёв при повторных переключениях и закрытие окна вместе с HUD.
