# Cosmic Radiation Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline. Verify each task before completion.

**Goal:** Сделать долгую работу в космосе опасной и дать скафандрам встроенную защиту разной силы.

**Architecture:** Сервер добавляет космический фон в штатный цикл RadiationSystem, до обновления дозиметров. Повреждения остаются типа Radiation и лечатся штатно; отдельный компонент одежды снижает только космический фон. Помещения, планеты, пауза и призраки исключены.

**Tech Stack:** C#, ECS RobustToolbox, YAML PartialOnly, FTL, NUnit.

**Spec:** Пользователь согласовал постоянную радиацию в открытом космосе, защиту скафандра с закрытым шлемом и сокращение сроков из-за двухчасовых смен. Ориентир реализации: 3–5 минут для EVA, 8–12 для специализированного комплекта до примерно 15 единиц Radiation у человека. Это ориентир повреждений, а не гарантированный порог симптомов для каждого вида.

## Global Constraints

- Orbitra, `_Orbitra`, русские объясняющие комментарии, минимальный hook в upstream.
- Не менять обычную радиационную броню и лечение; учитывать врождённые сопротивления.
- Короткая вылазка посильна; облучение прекращается в укрытии, повреждение сохраняется.
- Проверки последовательно, ограничение heap .NET, остановить все проверочные процессы.

## Review Focus

- Снятый шлем и предмет в руках не дают защиту.
- Планеты, nullspace, пауза, призраки не получают фон.
- Штатные дозиметры показывают фон без повторного урона от обычной радиации.
- Отрицательные, бесконечные и чрезмерные настройки не дают исцеление или неуязвимость.
- Контейнеры/инвентарь и перемещения не обходят проверку места; штатное лечение сохраняется.
